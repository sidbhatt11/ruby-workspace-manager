# Contributing

Thanks for your interest in RWM. Please read this before opening anything — it
will save us both time.

## This is a solo project, on purpose

RWM is built and maintained by one person ([Sid](https://github.com/sidbhatt11)),
and that's a deliberate choice, not a gap waiting to be filled. The project is
two experiments running at once: it's a **learning vehicle** for me, and its
development is **AI-assisted** — itself an experiment in how far that workflow
can carry a real, published tool. So far both are paying off, and keeping
authorship singular is what keeps the results legible.

## Code contributions: not right now

**I'm not accepting pull requests at this point.** Please don't invest effort in
one — it will be declined kindly, but declined. This may change after 1.0.

## Everything else: very much yes

RWM has no telemetry and never will, so the channels below are the only way the
project learns anything:

- **[Issues](https://github.com/sidbhatt11/ruby-workspace-manager/issues)** —
  bug reports, ideally with reproduction steps. The
  [1.0 milestone](https://github.com/sidbhatt11/ruby-workspace-manager/milestone/1)
  shows what's already known and planned; a 👍 on an issue genuinely affects
  priority.
- **[Discussions](https://github.com/sidbhatt11/ruby-workspace-manager/discussions)** —
  questions, ideas, experience reports, praise, complaints, "we tried it and
  bounced off because…" stories. All of it is useful.
- **Security** — please report privately via [SECURITY.md](SECURITY.md), not in
  a public issue.
