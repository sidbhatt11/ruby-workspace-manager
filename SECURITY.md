# Security Policy

## Supported Versions

Until we reach 1.0, only the **latest** release receives security patches. We recommend pinning to `~>` (pessimistic) in your Gemfile and keeping it up to date:

```ruby
gem "ruby_workspace_manager", "<= 1.0"
```

This policy may change after 1.0, when we expect to support multiple minor release lines.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately via [GitHub Security Advisories](https://github.com/sidbhatt11/ruby-workspace-manager/security/advisories/new).

Do not open a public issue for security vulnerabilities.

You can expect an initial response within 72 hours. Once confirmed, a fix will be prioritized and released as a patch version.
